## Run on any runtime

Every showcase runs on GJS by default — and, through the
[`@gjsify/node-gi`](/gjsify/projects/node-gi/) reverse bridge, on Node.js, Bun
or Deno too. Pick the runtime with `--runtime`:

```bash
npx @gjsify/cli showcase canvas2d-fireworks --runtime bun
```

Same GTK 4 window, same source, a different JS engine underneath. See
[Runtimes](/gjsify/runtimes/) for how the bridge works in both directions.
