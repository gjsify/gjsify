These widgets show state and identity rather than collect input. Use an
**avatar** for a person or account, a **banner** for an in-context message, a
**shortcut label** to draw a keyboard shortcut as keycaps, a **spinner** while
work is running, a **status page** for an empty or error state, and a **window
title** in a header bar.

:::note
The previews run the browser port, so behaviour Libadwaita drives natively (a
spinner's animation timing, a banner's reveal transition) can be simplified here.
The NativeScript port diverges in two places worth knowing: its avatar has no
icon fallback, and its banner takes plain text rather than markup.
:::

## Avatar

Stand in for a person, account or entity. Ask for **initials** and give it a
**name**, and it derives the initials and a stable background colour from that
name; with either missing it falls back to a symbolic **icon**. **Size** scales
it from an inline list glyph up to a full profile header.

<AdwWidget title="Adw.Avatar" blueprint="adwaita/avatar.blp">
  <Fragment slot="gjs">
    ```ts
    import Adw from 'gi://Adw?version=1';
    import Gtk from 'gi://Gtk?version=4.0';
    import ui from './avatar.blp';

    Adw.init();
    const builder = Gtk.Builder.new_from_string(ui, -1);
    const avatar = builder.get_object('avatar') as Adw.Avatar;
    avatar.text = 'Grace Hopper';
    ```
  </Fragment>
  <Fragment slot="webloader">
    ```js
    import '@gjsify/adwaita-web';

    const avatar = document.querySelector('#avatar');
    avatar.setAttribute('text', 'Grace Hopper');
    ```
  </Fragment>
  <Fragment slot="nativescriptloader">
    ```ts
    import { type Adw } from '@gjsify/adwaita-nativescript';
    import { Builder } from '@nativescript/core';

    const avatar = Builder.load({ path: '~/views', name: 'avatar' }) as Adw.Avatar;
    avatar.text = 'Grace Hopper';
    ```
  </Fragment>
</AdwWidget>

## Banner

Surface one in-context status message across the top of a view: a metered
connection, an offline state, a pending action. A banner takes a **title** and an
optional action **button**, and it reveals and hides itself, so it only occupies
space while the message applies.

<AdwWidget title="Adw.Banner" blueprint="adwaita/banner.blp" stage="flex-direction: column; align-items: stretch;">

## Shortcut Label

Draw a keyboard shortcut as **keycaps** instead of writing it out in prose. You
give it one **accelerator** string and it renders the keys in GTK's fixed order,
whatever order you wrote the modifiers in. The string has four levels: a space
lists **alternatives**, `...` is a **range**, `+` means the shortcuts are pressed
**in sequence**, and `&` means they are held **together**. An empty accelerator
shows the **disabled-text** placeholder instead.

<AdwWidget title="Adw.ShortcutLabel" blueprint="adwaita/shortcut-label.blp">
  <Fragment slot="gjs">
    ```ts
    import Adw from 'gi://Adw?version=1';
    import Gtk from 'gi://Gtk?version=4.0';
    import ui from './shortcut-label.blp';

    Adw.init();
    const builder = Gtk.Builder.new_from_string(ui, -1);
    const copy = builder.get_object('copy_shortcut') as Adw.ShortcutLabel;
    copy.accelerator = '<Control><Shift>C';
    ```
  </Fragment>
  <Fragment slot="webloader">
    ```js
    import '@gjsify/adwaita-web';

    const copy = document.querySelector('#copy_shortcut');
    copy.setAttribute('accelerator', '<Control><Shift>C');
    ```
  </Fragment>
  <Fragment slot="nativescriptloader">
    ```ts
    import { type Adw, type Gtk } from '@gjsify/adwaita-nativescript';
    import { Builder } from '@nativescript/core';

    const box = Builder.load({ path: '~/views', name: 'shortcut-label' }) as Gtk.Box;
    const copy = box.getViewById<Adw.ShortcutLabel>('copy_shortcut')!;
    copy.accelerator = '<Control><Shift>C';
    ```
  </Fragment>
</AdwWidget>

## Spinner

Show that work is running when you cannot say how much is left. The spinner turns
continuously while visible and scales to any **size**, from an inline glyph to a
page-filling placeholder. If you do know the progress, use a progress bar
instead.

<AdwWidget title="Adw.Spinner">
  <Fragment slot="preview">
    ```html
    <adw-spinner size="48"></adw-spinner>
    ```
  </Fragment>
  <Fragment slot="gjs">
    ```ts
    import Adw from 'gi://Adw?version=1';
    import Gtk from 'gi://Gtk?version=4.0';

    const spinner = new Adw.Spinner({
        widthRequest: 48,
        heightRequest: 48,
        halign: Gtk.Align.CENTER,
        valign: Gtk.Align.CENTER,
    });
    ```
  </Fragment>
  <Fragment slot="blueprint">
    ```blueprint
    using Gtk 4.0;
    using Adw 1;

    Adw.Spinner {
      width-request: 48;
      height-request: 48;
    }
    ```
  </Fragment>
  <Fragment slot="nativescript">
    ```ts
    import Adw from 'gi://Adw?version=1';

    const spinner = new Adw.Spinner({ size: 48 });
    ```
  </Fragment>
</AdwWidget>

## Status Page

Fill an empty, error or welcome screen with a centred placeholder: a large
symbolic **icon**, a **title** and a **description**. Add a **child** widget to
give the user a way out, such as a button that creates their first document.

<AdwWidget title="Adw.StatusPage" padding="flush" stage="height: 320px; display:flex;">
  <Fragment slot="preview">
    ```html
    <!-- description: The description markup to be displayed below the title. -->
    <adw-status-page icon="folder" title="No Documents" description="Documents you create or open will appear here.">
      <gtk-button label="New Document" pill suggested></gtk-button>
    </adw-status-page>
    ```
  </Fragment>
  <Fragment slot="gjs">
    ```ts
    import Adw from 'gi://Adw?version=1';
    import Gtk from 'gi://Gtk?version=4.0';

    const button = new Gtk.Button({
        label: 'New Document',
        halign: Gtk.Align.CENTER,
        cssClasses: ['pill', 'suggested-action'],
    });

    const statusPage = new Adw.StatusPage({
        iconName: 'folder-symbolic',
        title: 'No Documents',
        description: 'Documents you create or open will appear here.',
        child: button,
    });
    ```
  </Fragment>
  <Fragment slot="blueprint">
    ```blueprint
    using Gtk 4.0;
    using Adw 1;

    Adw.StatusPage {
      icon-name: "folder-symbolic";
      title: _("No Documents");
      description: _("Documents you create or open will appear here.");

      child: Gtk.Button {
        label: _("New Document");
        halign: center;

        styles ["pill", "suggested-action"]
      };
    }
    ```
  </Fragment>
  <Fragment slot="nativescript">
    ```ts
    import Adw from 'gi://Adw?version=1';
    import Gtk from 'gi://Gtk?version=4.0';

    const button = new Gtk.Button({
        label: 'New Document',
        horizontalAlignment: 'center',
        styleClasses: 'pill suggested-action',
    });

    const statusPage = new Adw.StatusPage({
        iconName: 'folder-symbolic',
        title: 'No Documents',
        description: 'Documents you create or open will appear here.',
        child: button,
    });
    ```
  </Fragment>
</AdwWidget>

## Window Title

The title widget a header bar expects: a **title** with an optional **subtitle**,
already sized and styled for that spot. Leave the subtitle empty and it collapses,
so a single-line title stays vertically centred.

<AdwWidget title="Adw.WindowTitle" blueprint="adwaita/window-title.blp">
  <Fragment slot="gjs">
    ```ts
    import Adw from 'gi://Adw?version=1';
    import Gtk from 'gi://Gtk?version=4.0';
    import ui from './window-title.blp';

    Adw.init();
    const builder = Gtk.Builder.new_from_string(ui, -1);
    const windowTitle = builder.get_object('window_title') as Adw.WindowTitle;
    windowTitle.subtitle = '4 unread messages';
    ```
  </Fragment>
  <Fragment slot="webloader">
    ```js
    import '@gjsify/adwaita-web';

    const windowTitle = document.querySelector('#window_title');
    windowTitle.setAttribute('subtitle', '4 unread messages');
    ```
  </Fragment>
  <Fragment slot="nativescriptloader">
    ```ts
    import { type Adw } from '@gjsify/adwaita-nativescript';
    import { Builder } from '@nativescript/core';

    const windowTitle = Builder.load({ path: '~/views', name: 'window-title' }) as Adw.WindowTitle;
    windowTitle.subtitle = '4 unread messages';
    ```
  </Fragment>
</AdwWidget>
