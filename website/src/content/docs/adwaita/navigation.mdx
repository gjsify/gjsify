These widgets move the user between the top-level places of your app, and they
adapt that movement to the window size for free. On a wide window a sidebar and
its content sit side by side. As the window narrows, the same structure folds
into a stack you push and pop, or into a panel that overlays the content. You
build one structure, not two.

:::note
These are the widgets that lean hardest on Libadwaita: adaptive breakpoints,
gesture-driven overlays, animated push and pop, back-swipe. The previews run the
browser port, so each shows one representative state (sidebar shown, sheet open)
and the collapse, overlay and slide interactions are simplified.
:::

## Navigation Split View

The workhorse for a mail-client or settings layout: a resizable **sidebar beside
a content pane**. On a wide window the two sit side by side. When the window is
narrow the view **collapses** into a single navigation stack, so selecting a
sidebar row pushes the content page and a back button returns to the list. Give
the sidebar and the content each their own navigation page and header bar.

<AdwWidget title="Adw.NavigationSplitView" blueprint="adwaita/navigation-split-view.blp" padding="flush" stage="height: 340px; width: 100%; display: grid; justify-content: stretch; overflow: hidden;">
  <Fragment slot="gjs">
    ```ts
    import Adw from 'gi://Adw?version=1';
    import Gtk from 'gi://Gtk?version=4.0';
    import ui from './navigation-split-view.blp';

    Adw.init();
    const builder = Gtk.Builder.new_from_string(ui, -1);
    const splitView = builder.get_object('split_view') as Adw.NavigationSplitView;
    const sidebar = builder.get_object('sidebar') as Adw.Sidebar;
    const status = builder.get_object('status') as Adw.StatusPage;
    sidebar.connect('activated', () => {
        status.title = sidebar.selectedItem?.title ?? '';
        splitView.showContent = true;
    });
    ```
  </Fragment>
  <Fragment slot="webloader">
    ```js
    import '@gjsify/adwaita-web';

    const splitView = document.querySelector('#split_view');
    const sidebar = document.querySelector('#sidebar');
    const status = document.querySelector('#status');
    sidebar.addEventListener('activated', () => {
        status.setAttribute('title', sidebar.selectedItem?.title ?? '');
        splitView.setAttribute('show-content', '');
    });
    ```
  </Fragment>
  <Fragment slot="nativescriptloader">
    ```ts
    import { type Adw } from '@gjsify/adwaita-nativescript';
    import { Builder } from '@nativescript/core';

    const splitView = Builder.load({ path: '~/views', name: 'navigation-split-view' }) as Adw.NavigationSplitView;
    const sidebar = splitView.getViewById<Adw.Sidebar>('sidebar')!;
    const status = splitView.getViewById<Adw.StatusPage>('status')!;
    sidebar.connect('activated', () => {
        status.title = sidebar.selectedItem?.title ?? '';
        splitView.showContent = true;
    });
    ```
  </Fragment>
</AdwWidget>

## Overlay Split View

Also a sidebar **beside** the content, but with a different collapsed behaviour:
instead of replacing the content, the sidebar slides **over the top** of it as a
temporary panel above a dimming scrim. Choose this one for a utility, filter or
navigation pane that should not push the main content aside on a narrow window.

<AdwWidget title="Adw.OverlaySplitView" blueprint="adwaita/overlay-split-view.blp" padding="flush" stage="height: 340px; width: 100%; display: grid; justify-content: stretch; overflow: hidden;">
  <Fragment slot="gjs">
    ```ts
    import Adw from 'gi://Adw?version=1';
    import Gtk from 'gi://Gtk?version=4.0';
    import ui from './overlay-split-view.blp';

    Adw.init();
    const builder = Gtk.Builder.new_from_string(ui, -1);
    const splitView = builder.get_object('split_view') as Adw.OverlaySplitView;
    const sidebar = builder.get_object('sidebar') as Adw.Sidebar;
    // Collapsed, the sidebar covers the content, so choosing a section closes it.
    sidebar.connect('activated', () => {
        if (splitView.collapsed) splitView.showSidebar = false;
    });
    ```
  </Fragment>
  <Fragment slot="webloader">

  </Fragment>

## Navigation View

A **navigation stack**: push a page, pop it, and get the back button for free.
The root page shows first. Pushing slides the next page in from the trailing edge
when transitions are animated, and a back-swipe gesture takes the user back.

A page carries a **tag**, and the code below pushes the detail page by its tag when
**Open contact** is clicked. The preview builds the file alone, without that code,
so it shows the root page.

<AdwWidget title="Adw.NavigationView" blueprint="adwaita/navigation-view.blp" padding="flush" stage="height: 340px; width: 100%; display: grid; justify-content: stretch; overflow: hidden;">
  <Fragment slot="gjs">
    ```ts
    import Adw from 'gi://Adw?version=1';
    import Gtk from 'gi://Gtk?version=4.0';
    import ui from './navigation-view.blp';

    Adw.init();
    const builder = Gtk.Builder.new_from_string(ui, -1);
    const view = builder.get_object('navigation_view') as Adw.NavigationView;
    const open = builder.get_object('open_button') as Gtk.Button;
    open.connect('clicked', () => view.push_by_tag('detail'));
    ```
  </Fragment>
  <Fragment slot="webloader">
    ```js

    const view = document.querySelector('#navigation_view');
    const open = document.querySelector('#open_button');

    ```
  </Fragment>
  <Fragment slot="nativescriptloader">

## Sidebar

The list that goes inside a split view: **selectable items** grouped into titled
sections, where selecting one drives the content beside it. Each item takes a
title, an optional subtitle and a leading icon. Two modes let it adapt: a
persistent `sidebar` for wide layouts and a full-width `page` for narrow ones.

Use this rather than a boxed list. A boxed list draws itself as a settings card,
which looks wrong edge to edge in a pane; a sidebar is a flat selectable list and
already knows how to be one.

## Bottom Sheet

A sheet that **slides up from the bottom edge** over the content it belongs to,
which suits contextual actions and secondary content on a narrow window. Make it
**modal** to dim the content behind it. `canClose` is on by default, so Escape or
a click on the dimmed area dismisses the sheet; switch it off to keep the sheet
up until your own code closes it. The preview starts with the sheet up: click the
dimmed area to dismiss it. Bringing it back is a property set (`open = true`), which
the code below wires to the button; the preview builds the file alone, so there the
button shows the content pane and does nothing.

<AdwWidget title="Adw.BottomSheet" blueprint="adwaita/bottom-sheet.blp" padding="flush" stage="height: 340px; width: 100%; display: grid; justify-content: stretch; overflow: hidden; position: relative;">
  <Fragment slot="gjs">
    ```ts
    import Adw from 'gi://Adw?version=1';
    import Gtk from 'gi://Gtk?version=4.0';
    import ui from './bottom-sheet.blp';

    Adw.init();
    const builder = Gtk.Builder.new_from_string(ui, -1);
    const sheet = builder.get_object('sheet') as Adw.BottomSheet;
    const toggle = builder.get_object('toggle') as Gtk.Button;
    toggle.connect('clicked', () => {
        sheet.open = !sheet.open;
    });
    ```
  </Fragment>
  <Fragment slot="webloader">
